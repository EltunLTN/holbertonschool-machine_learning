# Clustering

This directory contains the clustering tasks for the Holberton School
machine-learning project.

Implemented tasks:

- `6-expectation.py` - GMM expectation step
- `7-maximization.py` - GMM maximization step
- `8-EM.py` - Expectation-Maximization algorithm
- `9-BIC.py` - Bayesian Information Criterion model selection
- `10-kmeans.py` - K-means using scikit-learn
- `11-gmm.py` - Gaussian Mixture Model using scikit-learn
- `12-agglomerative.py` - Ward agglomerative clustering

The files target Python 3.9 and the library versions specified by the
project requirements.
